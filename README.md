# HR Management System — Hackathon, 2nd place

> **Archived.** Early work from 2025, kept for the record. Current projects are on
> [github.com/mouminkam](https://github.com/mouminkam) and [moumen-alkamsheh.vercel.app](https://moumen-alkamsheh.vercel.app).

Built in 24 hours at a Bytes4Future hackathon, where it took **second place**. HR teams manage employee records, attendance, roles and permissions from one dashboard.

**Stack:** React · Vite · Tailwind CSS · Node.js · Express · MongoDB (Mongoose) · JWT

**Layout:** `frontend/` — the React client · `backend/` — the Express API

## Running it

Each half installs separately (`npm install`, then `npm run dev` in the client and `npm start` or `node` in the server).
The server reads its settings from `backend/.env`; copy `backend/.env.example` and fill in your own values.
